개인정보 처리방침

최종 업데이트: 2026년 11월 4일

SiteKPI(sitekpi.net, 이하 “서비스”)가 수집하는 정보, 그 이용 방법, 삭제 방법을 설명합니다.

1. 서비스 소개

서비스는 선택한 사이트의 Google 애널리틱스 4(GA4) 숫자를 보여 주고, 이전 기간 및 공개된 업계 기준과 비교합니다. GA4 접근은 읽기 전용입니다.

2. 이용하는 Google 사용자 데이터

  • 권한 범위: https://www.googleapis.com/auth/analytics.readonly 하나뿐입니다.
  • 읽는 내용: 볼 수 있는 GA4 계정·속성 목록, 선택한 속성 1개의 집계 보고서(사용자·세션·이벤트·유입·기기·매출 등의 합계). 방문자 개개인의 데이터는 읽지 않습니다.
  • 이용 목적: 연 보드·행동 흐름·지표 화면을 보여 주는 데에만 씁니다. 화면을 빠르게 하려고 보고서 결과를 서버 메모리에 최대 5분 보관하며, 데이터베이스에는 저장하지 않습니다.
  • 하지 않는 것: GA4 설정·데이터 변경, Google 사용자 데이터의 판매·공유, 광고 이용, AI·머신러닝 모델 학습 이용은 하지 않습니다.

SiteKPI’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.(Google API로 받은 정보의 이용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.)

3. 저장하는 정보

  • 로그인 세션: Google OAuth 토큰과 선택한 속성을 서버 쪽 세션에 암호화해 저장합니다. 브라우저 쿠키에는 무작위 세션 ID만 들어갑니다. 14일 동안 쓰지 않은 세션은 만료됩니다.
  • GA4 속성별 보드 설정: 고친 흐름의 단계·이벤트 이름, 自社目安 범위. 다음에 같은 속성을 열 때 같은 설정으로 보여 주기 위해서입니다.
  • 보내 주신 의견: 화면, 👍/👎, 쓴 의견, 표시 언어, 속성 연결 여부. IP 주소나 Google 계정은 저장하지 않습니다.

저장 위치는 Google Cloud(Cloud Run·Firestore)입니다. 광고용 쿠키나 제3자 추적 도구는 쓰지 않습니다.

4. 데이터 삭제

  • 메뉴의 「연결·해제」에서 연결을 해제하면 세션을 삭제하고 Google 쪽 토큰도 무효로 합니다.
  • Google 계정의 타사 앱 액세스에서도 언제든 SiteKPI의 접근을 해제할 수 있습니다.
  • 속성별로 저장한 보드 설정의 삭제는 6.의 연락처로 알려 주세요.
