1. 運営者

本サービスは、{{ op.name }}（所在地: {{ op.address }}）が個人で運営しています。個人情報保護法上の個人情報取扱事業者として、本ポリシーに定める情報の管理に責任を負います。

2. 適用範囲

本ポリシーは、sitekpi.net 上のすべてのページ（ホーム、ボード、指標辞典、見本ボード、設定など）と、本サービスが Google API を通じて取得する情報に適用されます。本サービスからリンクしている外部サイト（Google、出典として示す調査会社のページなど）には、それぞれの運営者のポリシーが適用されます。

3. 取得する情報

本サービスは会員登録を行わず、氏名・メールアドレス・電話番号・住所などを入力していただくことはありません。取得するのは次の情報だけです。

  • Google の認証情報: 「GA4 を接続」を押して Google の画面で許可したときに発行される OAuth のアクセストークンとリフレッシュトークン。Google アカウントのパスワードを本サービスが受け取ることはありません。
  • GA4 の一覧と集計レポート: 見ることのできる GA4 アカウントとプロパティの名前・ID、選んだ 1 つのプロパティの集計値（ユーザー数・セッション・ページビュー・イベント数・流入元・デバイス・売上などの合計や割合）。訪問者一人ひとりを識別できるデータは要求しません。
  • ボードの設定: 選んだプロパティ、業種、期間、表示言語、直した流れの段とイベント名、分かれ道、自社目安の範囲。
  • ご意見: 「メモ・ご意見」または「ご意見」から送られたメモ・コメント（500 文字まで）、任意の 👍/👎、送った画面と見ていた部分・パス、表示言語、プロパティ接続の有無（接続済み・未接続）、送信日時。送ったメモはお使いのブラウザ（ローカルストレージ）にも一覧として残りますが、再送信はしません。
  • 本サービスの利用状況: 開いたページ、押したボタン、表示言語、接続の有無。Google アナリティクスで計測します（6. を参照）。
  • アクセスログ: ページを開いたときにサーバーが自動で記録する IP アドレス、ブラウザの種類（User-Agent）、URL、日時、応答コード。Google Cloud の標準機能で記録されます。

4. 利用目的

取得した情報は、次の目的の範囲でのみ利用します。

  1. 選んだ GA4 プロパティのボード・行動フロー・指標の表示と、前の期間・業界目安との比較
  2. 次に開いたときに同じ設定でボードを表示すること
  3. 不正アクセスや過度な負荷の検知・防止、障害の調査
  4. 本サービスの利用状況の把握（どの画面・機能が使われているか）
  5. いただいたご意見をもとにした画面・文言・機能の改善
  6. お問い合わせへの回答

上記以外の目的で利用する場合は、あらかじめ本ポリシーを改定し、必要に応じて同意をいただきます。

5. Google ユーザーデータの取り扱い

  • スコープ: https://www.googleapis.com/auth/analytics.readonly のみを要求します。GA4 の設定やデータを変更する権限は要求しません。
  • 使い方: 利用者が開いた画面の表示のためだけに使います。表示を速くするため、レポートの結果をサーバーのメモリに最大 5 分保持します。レポートの結果をデータベースに保存することはありません。
  • 「自分の AI に聞く」: ボードに表示した数字から、AI に貼り付けるための文章をお使いのブラウザの中で作ります。SiteKPI はこの文章をどこにも送信しません。コピーして他のサービス（ChatGPT など）に貼り付けるかどうかは利用者の判断で、貼り付けた先ではそのサービスの規約・ポリシーが適用されます。サイト名は初期設定で含めません。
  • 人による閲覧: 運営者を含め、人が利用者の GA4 データを見ることはありません。例外は、利用者の明示的な同意がある場合、セキュリティ上の調査に必要な場合、法令に従う場合だけです。
  • 行わないこと: Google ユーザーデータの販売、広告（ターゲティング広告・リターゲティング・興味関心に基づく広告を含む）への利用、信用力の判断や融資目的での利用、データブローカーなどへの移転、AI・機械学習の汎用モデルの開発・学習への利用は行いません。

SiteKPI’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.（Google API から受け取った情報の利用と他アプリへの移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。）

6. Cookie と外部送信

本サービスが使う Cookie は次の 2 種類です。広告用 Cookie や SNS のボタンなどは使いません。

  • セッション Cookie: ログイン状態を保つためのランダムなセッション ID。トークンや GA4 のデータは入っていません。
  • Google アナリティクスの Cookie（_ga など）: 本サービス自体の利用状況（開いたページ、押したボタン、表示言語、接続の有無）を知り、画面を改善するために使います。あなたの GA4 プロパティの名前・ID・数字など、Google API から受け取った情報は送りません。計測を止めたい場合は Google アナリティクス オプトアウト アドオンをご利用ください。

電気通信事業法に基づき、利用者のブラウザから外部に送られる情報を公表します。

送信先送られる情報目的
Google Fonts（Google LLC）IP アドレス、User-Agent、表示しているページの URL画面の文字（フォント）の表示
Google タグマネージャー・Google アナリティクス（Google LLC）Cookie の ID、IP アドレス、User-Agent、ページの URL、押したボタンと画面名本サービス自体の利用状況の計測と改善
Google アカウントの認証画面（Google LLC）接続ボタンを押したときのみ。本サービスのクライアント ID、要求するスコープGA4 への読み取りアクセスの許可

7. 第三者への提供

運営者は、次の場合を除き、取得した情報を第三者に提供しません。

  • 利用者の同意がある場合
  • 法令に基づく場合（裁判所・警察などからの適法な要請を含む）
  • 人の生命・身体・財産の保護のために必要で、同意を得ることが難しい場合

ご意見は、個人を識別できない形に集計したうえで、改善の報告などに使うことがあります。

8. 業務の委託と外国にある第三者

本サービスは、サーバーとデータの保管を Google Cloud（Google LLC。Cloud Run、Firestore、Cloud Logging、Secret Manager）に委託しています。データは米国のリージョン（us-central1）に保存されます。

  • 国名: アメリカ合衆国
  • その国の個人情報保護制度: 個人情報保護委員会が公表している外国における個人情報の保護に関する制度の情報をご覧ください。
  • 委託先が講じている措置: Google Cloud は ISO/IEC 27001・27017・27018、SOC 2 などの認証を受け、保存時と通信時の暗号化を行っています。運営者は Google Cloud の利用規約とデータ処理条項（Cloud Data Processing Addendum）に基づいて委託しています。

10. 安全管理措置

  • 通信はすべて HTTPS で暗号化します。
  • OAuth トークンはサーバー側で暗号化（Fernet）して保存し、暗号鍵は Secret Manager で管理します。
  • データベースとサーバーにアクセスできるのは運営者のアカウントだけで、二段階認証を設定しています。
  • 依存するライブラリを定期的に更新し、既知の脆弱性に対応します。
  • 情報の漏えいなどが起きた場合は、法令に従い、個人情報保護委員会への報告と利用者への通知を行います。

11. データの削除と接続の解除

  • メニューの「接続・切断」で切断すると、セッションを削除し、Google 側のトークンも無効にします。
  • Google アカウントのサードパーティ製アプリへのアクセスからも、いつでも SiteKPI のアクセスを外せます。
  • プロパティごとに保存したボード設定やご意見の削除は、15. のお問い合わせ先へご連絡ください。プロパティ ID を確認のうえ、30 日以内に削除します。
