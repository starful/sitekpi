### Day-15 verdict

| Signal | Next |
|--------|------|
| Relevant clicks, ~0 demo/connect | Stop ads; fix landing/connect only |
| Junk clicks / bad CPC | Stop; search experiment failed |
| ≥1 demo or connect | Discuss another 14 days, same keywords/budget only |
